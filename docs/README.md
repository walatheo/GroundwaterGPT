# Documentation Guide

This repository keeps a small set of living documents for the manuscript-facing system.

## Core Docs

- [EAGLE_TECHNICAL_OVERVIEW.md](EAGLE_TECHNICAL_OVERVIEW.md)
  Audit-oriented system description for manuscript and reviewer use.
- [MANUSCRIPT_DRAFT.md](MANUSCRIPT_DRAFT.md)
  Submission-oriented manuscript draft focused on the Florida USGS data pipeline, claim/evidence binding, and cross-cohort presentation.
- [DEVELOPMENT_GUIDE.md](DEVELOPMENT_GUIDE.md)
  Architecture, developer workflow, and implementation conventions.
- [ENGINEERING_STANDARDS.md](ENGINEERING_STANDARDS.md)
  Research-grade quality, testing, and review standards.
- [DEMO_RUNBOOK.md](DEMO_RUNBOOK.md)
  Deterministic demo and benchmark walkthrough.
- [SPONSOR_HANDOFF.md](SPONSOR_HANDOFF.md)
  Single-page operator handoff: prerequisites, fresh-clone setup, data, and known limitations. Pair with the root `HANDOFF.md` (engineering-successor notes).

## Intent

These docs are the maintained documentation set for the current system.
Historical sprint notes, task manifests, status summaries, and one-off session writeups were removed
so the repository reflects the application and manuscript more directly.
